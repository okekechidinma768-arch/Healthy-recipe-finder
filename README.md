# Healthy Recipe Finder

A responsive recipe-finder website recreated from the supplied design reference using plain HTML, CSS and JavaScript.

## Features
- Responsive desktop, tablet and mobile layouts
- Eight recipe cards with food photography
- Search recipes by name, description or ingredient
- Filter by maximum preparation time and cooking time
- Recipe details dialog with ingredients, instructions and timings
- Mobile navigation, empty-search state and reset filters
- Keyboard focus styles and semantic HTML

## Run locally
Open `index.html` in a browser. Food photography and Google Fonts load from external URLs, so an internet connection is needed for those assets.

## Publish with GitHub Pages
1. Create a new public repository on GitHub, for example `healthy-recipe-finder`.
2. Upload `index.html`, `styles.css`, `script.js`, and `README.md` to the repository's root folder.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then press **Save**.
6. Wait for GitHub Pages to publish the site. Your live link will look like `https://YOUR-USERNAME.github.io/healthy-recipe-finder/`.

Replace `YOUR-USERNAME` with your GitHub username. The exact live URL is only active after you publish it.
